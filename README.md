## Design Explanation

"Login Roulette" is an intentionally frustrating login experience built around the theme of gambling and chance. Instead of a standard login flow, the page features a slot machine that determines whether access is granted — the user can only log in if the reels land on 7-7-7, which occurs randomly with a ~15% probability. To even attempt a spin, the user must fill in a username and password field whose labels constantly change every 5 seconds (e.g. "Username" becomes "Soul ID" or "Spirit Animal Spelled Backwards"), type a password that must satisfy a new contradictory rule on every keystroke (such as "must be a palindrome" immediately followed by "emojis are strictly forbidden"), and correctly solve a math captcha that refreshes every 15 seconds. Every failed spin is met with a mocking message ("Come back tomorrow. Maybe the wheel likes you then.") and laughing emojis that fly onto the screen and accumulate permanently, increasingly cluttering the interface. If the jackpot is somehow hit, all emojis vanish and a fullscreen "ACCESS GRANTED" banner appears — a reward that feels genuinely earned after the chaos that preceded it.
